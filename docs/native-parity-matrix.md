# Native iOS Feature-Parity Matrix

Updated: 2026-09-25

This is the release ledger for the SwiftUI migration. A row may be marked
`Verified` only after model, behavior, failure-state, physical-device, and
automated-test parity are all demonstrated.

> **2026-09-16 owner sign-off:** physical-device and isolated-staging evidence is
> deferred to Phase 12 (see the deferral decision in
> [native-ios-migration-roadmap.md](native-ios-migration-roadmap.md#verification-deferral-decision-2026-09-16)).
> Rows stay short of `Verified` until those Phase 12 runs pass, but a row's
> "physical-device / staging proof remains" clause is no longer a per-phase
> release blocker — it is scheduled work for the TestFlight/beta stage.

## Status key

- `Not started` — no native implementation.
- `Prototype` — UI or simplified local behavior exists; not production parity.
- `In progress` — canonical migration work has begun.
- `Blocked` — named external decision or dependency is missing.
- `Verified` — acceptance criteria passed with recorded evidence.
